Why two columns, one layer

  • Front End and Business Logic are separate containers on the same docker bridge network, not separate hosts
  • nginx only proxies static assets; every API call goes straight to FastAPI on :8000

Pipeline node colors

  • LLM call — Gemini-backed (intake, summarizer)
  • deterministic gate (cost, rag, peer_review)
  • demo-mocked join node (alternative)
  • real LangGraph interrupt() (human_review)

What's not shown

  • No ALB / CloudFront / Route 53 — instance reached directly by IP or A record
  • No managed RDS / ElastiCache — Postgres and Redis are the containers themselves, on EBS-backed volumes
  • No autoscaling — one instance, one compose stack
